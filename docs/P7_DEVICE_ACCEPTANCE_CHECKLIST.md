# P7 真机验收清单（可勾选执行版）

> 用法：按 A→F 顺序在真机上执行。每条都有「怎么做 / 应该看到什么」。不通过的只记编号 + 现象 + 截图，不用当场排查。
> 截图命名：`manual-p7-<编号>-<机型>-<日期>.png`，全部放 `D:\kaifa\design\review\`。
> 截好之后在工程目录执行 `node tools/write_p7_evidence.js`，会把 `manual-p7-*.png` 与 `mask-diag-*.png` 一起登记进 `p7-evidence-manifest.json` 的 `deviceEvidence`；`node tools/validate_release_readiness.js` 的输出里会显示 `device=N`。
> 记录头：机型、系统版本、微信版本、基础库版本、是否真机调试模式。

本次验收机型：____________　系统：____________　微信：____________　基础库：____________
运行方式：____________（预览扫码 / 真机调试）

> **重要**：遮罩类问题务必在「预览」模式下至少复测一次。真机调试模式本身会在画面上叠微信自己的调试浮层（顶部「● 已连接　展开」），排查遮罩时要先排除它的干扰。

## A. 战斗拖拽手感（8 项）

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| A1 | 从手牌按住一张随从卡往上拖 | 卡跟着手指走，不跳变；预览卡不会挡住你要放的位置 |
| A2 | 手牌左右横滑，再长按一张 | 横滑不误触出牌；长按能出详情，手指松开详情消失 |
| A3 | 拖到己方随从之间左右移动 | 出现一条竖直插入线，位置随手指移动；松手后随从落在线的位置 |
| A4 | 拖一张随从卡撞敌方随从 | 目标随从有高亮/边框反馈，命中容易，不会"擦边不中" |
| A5 | 场上无城墙时，拖随从撞敌方英雄头像 | 英雄框高亮，松手后正常扣血（**本轮修复项**） |
| A6 | 敌方有城墙时，拖随从撞英雄 | 只出现"只能攻击城墙随从"类提示，不提交、不弹全屏弹窗 |
| A7 | 拖起后拖回手牌区域松手 | 卡回弹到手里，不打出、不扣能量 |
| A8 | 满场 7 张随从时选一个攻击 | 仍能选中并拖拽攻击，不误触相邻卡 |

## B. 本轮修复复测（7 项，最优先）

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| B1 | 换牌阶段连续点两次「确认起手」 | 只提交一次，**不弹**「起手换牌阶段已结束」弹窗 |
| B2 | 换牌确认后等 AI 行动结束 | 按钮显示「处理中…」期间不可重复点 |
| B3 | 出牌/攻击后观察整个战场 | **不出现整屏变暗的遮罩**（本轮核心问题） |
| B4 | 手动触发一次请求失败（关网络再出牌） | 只在战场中央出现一行提示，2.6 秒后自动消失；不弹全屏弹窗；随后自动与服务端对齐 |
| B5 | 打死一个敌方随从后看右侧墓地 | 墓地数量 +1，点开能看到该卡（**本轮修复项**） |
| B6 | 长按手牌/场上卡看详情 | 详情以面板形式出现，战场不整体压暗；松手或点卡外关闭 |
| B7 | 在「预览」模式下连出 3 张牌、攻击 2 次、快速连出 2 张，每次停顿 1 秒看画面 | **不应出现任何泛光/闪光/蒙层**，画面亮度始终保持稳定（本轮修复项：`battleFlash` 效果已按用户要求整体移除，D24） |

## C. 界面与入口（3 项）

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| C1 | 进主页 | 右上角微信胶囊不遮挡标题和任何入口 |
| C2 | 逐个点主页全部入口（含「调整公告」） | 11 个入口都能进、都能返回，无白屏 |
| C3 | 打开「调整公告」对比页 | 三张卡的改前/改后数值与立绘正确，红点可清 |

## D. 图鉴与工坊（4 项）

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| D1 | 进图鉴，等立绘分包加载 | 3 列完整卡面，加载期间有占位、不闪白 |
| D2 | 图鉴里长按一张卡 | 详情居中，不穿透到下层，松开消失 |
| D3 | 搜索 / 多选筛选叠加 | 名称、ID、规则、关键词都可搜；同类 OR、跨类 AND；清除后恢复 |
| D4 | 图鉴内分解与合成 | 分解无二次确认直接生效；合成上限正确（普通卡 9、闪卡按 3/2/2/1） |

## E. 对局完整性（4 项）

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| E1 | 完整打完一局（赢或输） | 结算页标题/副标题/数值正确，可返回主页 |
| E2 | 打完立刻看对战记录 | 新增且只有一条，字段（难度、结果、回合）正确 |
| E3 | 对局中途退出再进 | 出现续局提示，能恢复到退出时的局面 |
| E4 | 让 AI 连续行动几回合 | 1×/2× 倍速切换生效，逐步动画不卡顿、不跳帧 |

## F. 稳定性（2 项）

| 编号 | 怎么做 | 应该看到 |
| --- | --- | --- |
| F1 | 连续玩 15 分钟（含多局） | 无黑屏、无卡顿加剧、无点不动、无内存崩溃 |
| F2 | 切到后台再切回前台的战斗画面 | 画面正常重绘，不花屏、不残留遮罩 |
