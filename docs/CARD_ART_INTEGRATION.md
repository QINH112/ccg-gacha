### 验收标准

- 375px 与 430px 宽图鉴均使用 3 列；每张非闪版本和对应闪卡版本各占一个完整卡位。
- 非闪版本使用对应稀有度非闪卡框，闪卡版本始终使用对应稀有度闪卡框。
- 卡牌立绘通过 `card-art-mask-v1.png` 裁入蛋形窗口，不回退为几何符号占位。
- 卡面显示费用、名称、效果、攻击和生命，卡面下分别显示 `非闪 N` 或 `闪卡 N`。
- 未拥有卡牌允许降低透明度，但仍显示完整卡框和立绘，便于图鉴浏览。
- 单击卡牌进入详情；详情中的分解、合成和闪耀规则保持不变。
- 卡包筛选、长列表滚动和卡牌详情关闭区域均保持可用。

- 真机首次进入图鉴时仍需观察两个立绘分包的首次加载速度；加载失败时会按现有规则降级为几何占位，不阻塞操作。
- `smoke_service_interactions.js`、`smoke_service_scrolling.js` 和 `smoke_device_matrix.js` 仍包含旧主页固定坐标；新增“调整公告”入口后，这些测试的路由点击坐标已过期。此次使用图鉴专用视觉证据、源码防回退校验和开发者工具真实编译替代，不将旧坐标失败误判为图鉴渲染失败。
- 今后调整图鉴时，不得隐藏闪卡版本，也不得把非闪版本与闪卡版本塞进两个半宽卡位；两个版本必须各自使用完整卡面展示。
- 当前工作区中原批量母版与 `art-config.json` 已不存在；新增 `design/card-art/generated/e009.png` 与 `l004.png` 仅作为两张新卡的可追溯生成母版。运行时两个分包及其 `art-manifest.json` 完整保留，校验脚本会在源配置缺失时以 manifest 为准检查 74 张线上立绘。
