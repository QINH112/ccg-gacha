# 卡牌图鉴搜索与组合筛选计划

> 本文档记录在现有卡牌图鉴视觉与交互基础上新增“搜索 + 多条件组合筛选”的需求确认和实施边界。用户提供的图鉴截图仅作为当前样式参考，不把截图中的文字或装饰自动视为新增需求。

## 术语约定

- **非闪版本**：卡牌的基础版本。
- **闪卡版本**：卡牌的闪耀版本。
- **普通稀有度**：稀有度名称，不等同于非闪版本。

## 1. 当前图鉴样式确认

- 页面使用现有星界背景、顶部安全区和“星界卡牌图鉴”标题。
- 标题下方当前是一个“卡包筛选：全部卡包”按钮，点击后循环切换卡包。
- 卡牌区域固定 3 列。
- 非闪版本和闪卡版本分别占一个完整卡位，不使用半宽卡面。
- 卡面显示费用、立绘、名称、效果、攻击、生命和对应版本数量。
- 未拥有的非闪版本/闪卡版本仍展示完整卡面，但降低透明度。
- 卡牌下方分别显示“非闪 N”和“闪卡 N”。
- 单击卡牌打开详情页；详情页继续承载分解、合成此卡和闪耀操作。
- 本次需求保持上述整体布局、卡框、卡牌网格、滚动和详情交互不变，只替换顶部单一卡包按钮为搜索框与筛选按钮。

## 2. 已确认产品规则

### 2.1 顶部控件

- 顶部现有“卡包筛选”按钮改为两个控件：
  1. 搜索框
  2. 筛选按钮
- 搜索框与筛选按钮并列放在原顶部筛选区域，不改变卡牌网格的整体布局。
- 搜索框支持输入、清空和重新筛选；搜索结果应随输入内容更新，具体是否实时更新由实现时保持 Canvas 操作流畅性决定。
- 筛选按钮打开筛选面板；筛选面板关闭后保留已选条件。

### 2.2 搜索

- 搜索为模糊匹配，不要求完整输入。
- 搜索字段包括：
  - 卡牌名称
  - 卡牌 ID
  - 规则文字
  - 关键词及其中文显示文本
- 例如搜索“城墙”，应显示规则文字或关键词包含“城墙”的卡牌。
- 搜索与筛选同时生效，结果必须同时满足搜索条件和已选筛选条件。
- 搜索不改变非闪版本/闪卡版本的独立卡位展示：匹配到一张逻辑卡牌时，两个版本仍按版本筛选条件分别显示。

### 2.3 筛选类别

筛选支持以下类别，并允许同时组合：

- 卡包
- 稀有度
- 费用
- 版本：非闪版本 / 闪卡版本

未来可扩展其他类别，但第一版至少实现以上四类。

### 2.4 多选逻辑

- 每个筛选类别内部支持多选。
- 不同筛选类别之间使用“同时满足”的 AND 逻辑。
- 同一筛选类别内部使用“任一项匹配”的 OR 逻辑。
- 费用采用精确费用多选，不采用范围筛选；例如选择 `2费 + 3费`，只匹配费用为 2 或 3 的卡牌。
- 示例：

```text
卡包：基础卡牌包、星骸遗响
稀有度：史诗、传说
费用：2费、3费
版本：非闪版本、闪卡版本
```

结果必须同时满足四个类别，且每个类别命中所选任一项。

### 2.5 空状态与重置

- 搜索和筛选无匹配结果时，保留图鉴页面和顶部控件，显示明确的空结果提示，不显示错误弹窗。
- 提供清除筛选条件的路径。
- 清除筛选后，搜索文本同时清空，并通过“清除全部”一次恢复完整卡牌列表。
- 返回主页再进入图鉴时，搜索文本和所有筛选条件均重置为默认状态，重新显示完整卡牌列表。

## 4. 实施边界

### 允许修改

- `game.js`：图鉴顶部控件、搜索状态、筛选状态、筛选面板、结果过滤和命中区。
- 图鉴专用视觉审阅或交互回归脚本。
- 本计划文档和相关验收记录。

### 必须保持

- 现有图鉴完整卡面、固定三列和非闪版本/闪卡版本分别占完整卡位的视觉约束。
- 卡牌详情、分解、合成此卡、闪耀、库存数量和滚动交互。
- 卡牌 ID、卡包数据、稀有度、费用、规则文字、关键词和云存档结构。
- 不修改卡牌数值、战斗规则、工坊事务或卡牌艺术资源。

## 6. 已冻结的状态规则

- 返回主页后再次进入图鉴时，搜索文本和所有筛选条件均清空。
- 重新进入图鉴默认显示完整卡牌列表，卡包、稀有度、费用和非闪版本/闪卡版本筛选均恢复为“全部”。
- 该规则避免玩家在离开页面后再次进入时误以为卡牌缺失或结果仍受旧条件限制。
