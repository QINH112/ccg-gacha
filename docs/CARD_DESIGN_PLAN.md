## 术语约定

- **普通稀有度**：卡牌稀有度名称；设计表格中的“普通”均指普通稀有度。
- **非闪版本**：卡牌的基础版本，与闪卡版本相对；不再用稀有度名称代指该版本。
- **牌组携带上限**：普通稀有度 3 张、稀有 2 张、史诗 2 张、传说 1 张；非闪版本与闪卡版本合计计算。

## 1.2 2026-11-19 新增卡牌设计

### `e009` 沉默之墙

| 字段 | 设计 |
|---|---|
| 卡包 | 基础卡牌包 `base` |
| 稀有度 | 史诗 |
| 类型 | 随从 `minion` |
| 费用 | 5 |
| 攻击/生命 | 0/6 |
| 关键词 | 亡语 `deathrattle` |
| 规则文字 | 亡语：沉默所有随从。 |
| 效果定义 | `{ trigger:"deathrattle", action:"silence", target:"all-minions" }` |
| 背景描述 | 它崩塌时，战场上的誓言、祝福与诅咒都随碎石一同归于寂静。 |
| 状态 | 已实施并通过规则、数据、卡图与交互自动化验收 |

设计说明：

- “所有随从”包括双方场上仍存活的随从，不包括已经死亡并移出场面的「沉默之墙」自身。
- 亡语结算时，先按现有死亡流程移除死亡随从，再对双方剩余随从施加沉默。
- 沉默导致光环移除后，需要重新计算攻血并继续处理因此产生的死亡。

### `l004` 万籁归寂

| 字段 | 设计 |
|---|---|
| 卡包 | 基础卡牌包 `base` |
| 名称 | 万籁归寂 |
| 稀有度 | 传说 |
| 类型 | 法术 `spell` |
| 费用 | 1 |
| 攻击/生命 | 无 |
| 关键词 | 无 |
| 规则文字 | 沉默所有敌方随从。 |
| 效果定义 | `{ trigger:"cast", action:"silence", target:"all-enemy-minions" }` |
| 背景描述 | 无声的星潮掠过敌阵，所有天赋、祝福与誓约都在刹那间熄灭。 |
| 状态 | 已实施并通过规则、数据、卡图、统一施放与墓地自动化验收 |

设计说明：

- 这是项目第一张正式法术牌，必须新增 `spell` 卡牌类型，不能伪装成 0 攻随从。
- 法术不占随从场位，不显示攻击和生命值，也不受己方场面 7 张上限限制。
- 所有手牌类型统一通过战场中央的卡牌施放区域使用；该区域不是法术专属区域。
- 从手牌拖动「万籁归寂」进入中央施放区域并松手后，立即结算“沉默所有敌方随从”，随后从手牌移除。
- 随从牌支持两种召唤方式：拖入中央施放区域后自动排列到己方场面最右侧；或直接拖入己方场面的具体插槽，按指定位置召唤。
- 无需目标的法术牌拖入中央施放区域后直接结算；需要目标的法术牌必须选择合法目标后释放。
- 未来新增卡牌种类应根据“是否需要目标”和卡牌类型复用中央施放、指定插槽或目标选择机制。
- 有目标法术直接从手牌拖向合法目标卡牌或英雄并松手释放，不经过中央施放区域。
- 有目标法术拖入非法目标区域时，在战场中央立即显示具体原因；拖出非法区域、松手或取消后立即消失，与非法攻击提示规则一致。
- 法术结算后进入可查看的“墓地/已使用卡牌”区域，不能只从手牌删除或仅写入文字日志。
- 用户确认死亡随从与已使用法术进入同一墓地，并按结算顺序展示。
- 用户确认玩家与 AI 墓地使用两个独立入口查看，不在同一界面内切换。
- 双方墓地入口统一放在战场右侧，同时保留两个独立入口：敌方入口位于敌方区域右侧并靠近敌方牌库，我方入口位于我方区域右侧并靠近我方牌库。
- 点击任一入口后，打开该方墓地的完整卡牌列表，不使用长按临时预览。
- 完整墓地列表支持右上角关闭按钮；点击弹窗外的战场空白区域也会关闭弹窗。
- 完整墓地列表支持正序/倒序切换：正序从最早结算到最新结算，倒序从最新结算到最早结算。
- 排序仅改变列表展示，不得改变真实结算顺序或墓地记录。
- 首次打开墓地时默认使用倒序，最新进入墓地的卡牌显示在最前面。
- 我方与敌方墓地分别记忆各自的排序选择，切换一方不得影响另一方。
- 两方排序状态只在当前对局内分别记忆；开始新对局时均恢复默认倒序（最新卡牌在前）。
- 墓地列表中的卡牌采用统一详情交互：长按显示完整详情，松手或触摸取消时关闭。
- 不使用短按进入独立详情页的方式。
- 同一方墓地中的同名卡牌合并为一个条目，并显示累计数量；底层仍保留每次进入墓地的独立结算记录。
- 合并条目按该卡牌最近一次进入墓地的时间参与排序；同名卡牌再次进入墓地时更新数量、最近时间和列表位置。
- 合并条目的累计数量显示为卡牌右上角的圆形 `×N` 标记，例如 `×3`；只有 1 张时隐藏 `×1`，累计 2 张及以上时才显示。
- 战场上的双方墓地入口显示各自当前墓地计数，并随卡牌进入墓地即时更新。
- 入口计数表示实际进入墓地的卡牌总张数，不使用合并后的不同卡名条目数；同名卡合并只影响列表展示。
- 墓地计数为 `0` 时入口不可点击，不能打开空列表；首张卡牌进入后立即启用。
- 空墓地入口采用灰暗禁用样式；首张卡牌进入后恢复正常亮度和可点击状态。
- 墓地完整列表采用局部弹窗，不覆盖大部分战场，并尽可能保持战场状态与 AI 动画可见。
- 我方与敌方墓地都使用战场右侧同一固定弹窗区域，根据所点击的独立入口显示对应内容。
- 当前弹窗打开时点击另一方入口，直接在同一弹窗内切换对应墓地内容，无需先关闭；双方仍分别使用各自在当前对局内记忆的排序状态。
- 弹窗标题固定显示“我方墓地”或“敌方墓地”，切换入口时同步更新。
- 标题同时显示当前墓地实际卡牌总张数，格式为“我方墓地（X张）”或“敌方墓地（X张）”；合并条目按实际张数计入。
- 墓地列表不提供卡牌类型筛选，随从、法术等所有卡牌按当前排序统一混合展示。
- 墓地列表使用紧凑信息条目，不沿用图鉴完整卡图与卡框，仅显示费用、名称、攻击力和生命值。
- 法术等无攻血卡牌按类型显示为空或“不适用”，不生成伪造数值。
- 紧凑墓地条目显示稀有度，并沿用现有颜色规范区分品质：普通灰蓝、稀有蓝色、史诗紫色、传说金色。
- 墓地条目不额外显示“随从”或“法术”类型标识，保持紧凑展示。
- 长列表超出弹窗可视范围时使用纵向滚动，不分页；滚动仅作用于右侧墓地弹窗内部。
- 墓地弹窗内的纵向滚动条始终可见。
- 纵向滚动条滑块支持直接拖拽快速定位，不改变墓地记录和对局状态。
- 墓地弹窗打开期间 AI 动画继续播放，不暂停 AI 回合或战场状态；墓地弹窗为只读查看层。
- 墓地弹窗打开期间玩家仍可进行合法的拖牌、攻击和出牌操作；墓地查看不阻塞战场交互。
- 点击或拖动弹窗外战场区域时直接继续执行对应的合法操作，无需先关闭墓地弹窗。
- 弹窗外事件按目标区分：点击战场空白区域关闭弹窗；点击或拖动卡牌、英雄、技能等可交互对象时执行对应合法操作，并保持弹窗打开。
- 战场操作完成后墓地弹窗保持打开，并实时刷新当前查看方的计数、合并数量和列表内容。
- 墓地新增记录导致列表刷新时保持当前滚动位置，不强制跳转到顶部或最新条目，并继续使用当前方的排序选择。
- 新卡牌进入当前查看方墓地时，在对应条目上播放短暂提示动画；提示仅用于告知新增，不改变排序、滚动位置或对局节奏。
- 同名卡牌合并导致数量增加时，同样播放对应条目的提示动画，不强制改变当前滚动位置。
- 墓地新增提示动画同时播放提示音效；新条目与同名合并条目使用一致反馈。
- 墓地提示音效遵循游戏总音量与静音设置；静音或总音量为零时不播放，但保留视觉提示。
- 新条目与同名合并数量增加使用相同提示音效，不区分两类新增事件。
- 墓地条目不提供独立的短按选中效果；短按不改变状态或打开详情页，仅保留滚动与长按详情。
- 墓地条目不显示具体或相对入墓时间，时间仅用于内部排序与最近一次入墓时间计算。
- 墓地紧凑条目不显示规则文字摘要；规则文字和其他详细信息仅在长按卡牌时显示。
- 长按墓地条目时完全复用手牌和战场卡牌现有详情内容与布局，包括卡图、卡框、费用、攻血、规则文字、关键词、稀有度和背景说明。
- 墓地底层仍保留完整详情数据；紧凑列表不直接显示卡图、卡框或规则文字，与长按详情的完整展示相互独立。
- 长按详情显示期间允许拖动手指切换其他墓地条目，详情内容立即更新并持续显示，松手或触摸取消时关闭。
- 切换墓地条目时不播放额外触觉或音效反馈，仅更新详情内容。
- 长按拖动详情按合并后的墓地条目切换；底层逐次入墓记录只用于张数、排序与审计，不单独作为详情目标。
- 长按详情切换仅限当前墓地，不允许跨越到另一方墓地；切换双方必须点击对应独立入口。
- 详情拖动到当前列表顶部或底部时允许继续触发当前墓地列表的纵向边缘滚动，不改变排序或墓地方向。
- 边缘滚动使新条目进入可视区域时不自动切换详情；只有手指明确进入另一合并条目的有效命中区域时才更新详情。
- 最初长按条目离开可视区域后继续保持当前详情，直到手指明确进入其他合并条目或松手。
- 正序/倒序排序使用一个切换按钮，每次点击在两种状态间切换；双方墓地仍分别记忆各自状态。
- 单个排序按钮显示当前状态：按最早到最新排列时显示“正序”，按最新到最早排列时显示“倒序”，点击后立即更新文字。
- 排序按钮仅显示“正序”或“倒序”文字，不添加方向图标。
- 切换正序/倒序后，当前墓地列表回到顶部；另一方墓地的滚动位置与排序状态不受影响。
- 墓地弹窗占用区域属于卡牌不可释放区域，不触发出牌、攻击、目标结算或入墓。
- 拖拽进入弹窗区域后仍可拖出并继续选择合法目标；在该区域松手则取消动作，播放卡牌返回原位的回弹动画，且不提交战斗请求。
- 拖拽进入墓地弹窗区域时不显示“无法在墓地区域释放”或其他中央文字提示。
- 拖拽进入墓地弹窗区域时显示红色禁用描边；拖出、松手或取消后立即恢复，不显示文字提示。
- 墓地仅在对战进行中可查看；进入胜负结算界面后不提供双方墓地入口，也不能重新打开本局墓地列表。
- 对局结束瞬间若墓地弹窗已经打开，立即自动关闭弹窗及长按详情并进入结算界面。
- 墓地底层记录只在当前对局内保留；对局结束后清除，不写入对战历史、长期存档或下一局状态。
- 自动化测试可在对局结束前读取墓地状态进行验证，但不增加玩家可见的历史墓地入口。
- 墓地主要产品规则已完成本地实施；对局结束时清除墓地，不写入对战历史。
- AI 可使用无目标法术；通用目标法术只在存在合法目标时进入可用列表，并从合法目标中选择。

### 沉默规则规格

- 沉默使随从失去全部 `keywords` 与 `effects`，包括城墙、冲锋、突袭、护盾、吸血、入场、亡语、光环及未来扩展能力。
- 已经完成结算的入场效果不会被追溯撤销。
- 沉默立即移除当前护盾状态，并停止光环、亡语及其他持续/待触发能力。
- 沉默不移除随从已经受到的伤害，也不把当前攻血直接重置为印刷值；移除光环后按现有伤害保留规则重新计算。

- 再次沉默已沉默随从不叠加额外效果。
- 完整自动化测试至少覆盖：单体沉默、双方全体沉默、敌方全体沉默、护盾清除、城墙失效、亡语失效、光环移除、光环移除致死、吸血失效、突袭/冲锋状态清除、重复沉默与视觉快照字段。

### 3.1 关键词规则基线 v0.2（2026-11-17 用户确认）

这份候选稿以当前引擎能力为基础，目的是先建立一个可实现、容易理解且不会产生大量隐藏例外的版本。

#### 城墙

- 规则文字：只要一方场上存在具有“城墙”的随从，对方随从进行攻击时只能选择具有“城墙”的随从。
- 多个城墙同时存在时，攻击者可以在它们之间任意选择。
- 城墙只限制“随从攻击”，不阻止入场、亡语、英雄技能等效果对英雄或其他随从造成伤害。
- 城墙随从自身仍可正常攻击。

#### 冲锋

- 规则文字：该随从在被打出的回合即可攻击随从或敌方英雄。
- 冲锋不会增加每回合攻击次数，默认仍只能攻击一次。
- 设计限制：原则上不让同一张卡同时拥有冲锋和突袭；如果同时出现，以冲锋为准。
- 平衡要求：低费冲锋必须降低身材或提高费用，并接受单回合英雄伤害上限审查。

#### 突袭

- 规则文字：该随从在被打出的回合即可攻击敌方随从，但不能攻击敌方英雄。
- 从下一个己方回合开始，它可以像普通随从一样攻击英雄。
- 突袭仍受城墙限制：敌方存在城墙时，只能攻击城墙随从。

#### 护盾

- 规则文字：抵消该随从下一次受到的大于 0 的伤害，然后失去护盾。
- 战斗伤害和卡牌效果伤害都可以消耗护盾。
- 一次伤害无论数值多高都只消耗一层护盾并造成 0 点伤害。
- 伤害被护盾抵消时，伤害来源的吸血不会恢复生命。
- 当前设计不叠加多层护盾；再次获得护盾只保持“有护盾”状态。

#### 吸血

- 规则文字：该随从通过战斗实际造成伤害后，为己方英雄恢复等量生命。
- 只计算实际造成的伤害；被护盾抵消的部分不产生治疗。
- 第一版仅让战斗伤害触发吸血，入场和亡语造成的效果伤害不触发吸血。
- 英雄生命不能超过 30。

#### 入场

- 规则文字：从手牌正常打出该随从并使其进入场面后，立即执行其入场效果。
- 通过其他效果直接生成或召唤的随从不触发入场，除非效果明确写明。
- 入场效果在随从进入场面、光环刷新后结算。
- 入场效果结算完成后统一检查死亡与胜负。
- 当前引擎没有交互式选目标能力，因此第一版入场效果优先使用固定目标、英雄、全部随从或自身。

#### 亡语

- 规则文字：该随从死亡并从场面移除后，执行其亡语效果。
- 多个随从同时死亡时，按进入场面的先后顺序结算，先进入者先结算。
- 每个死亡实例只触发一次亡语。
- 亡语可能造成新的死亡；新产生的死亡在当前批次亡语之后继续结算。

#### 光环

- 规则文字：只要该随从在场，其他友方随从持续获得规则文字所述加成。
- 默认不影响光环来源自身；不同光环可以叠加。
- 光环来源离场后立即移除其加成。
- 移除生命加成时保留随从已经受到的伤害；若剩余生命降至 0 或以下，该随从死亡。
- 当前第一版光环仅考虑“其他友方随从获得 +攻击/+生命”，其他光环类型需先扩展引擎规格。

### 3.2 第一版规则设计原则

- 普通稀有度卡优先承担基础身材和单一关键词教学，不堆叠复杂效果。
- 稀有卡可以出现一个关键词加一个简单效果。
- 史诗卡可以形成构筑核心或组合技，但规则文字仍需能在手机卡面完整展示。
- 传说卡应有独特身份和强效果，不以纯粹超模身材代替设计。
- 第一版尽量避免交互式选目标，以匹配当前 PVE 操作与 AI 能力。
- 所有直接英雄伤害、抽牌、治疗、光环和冲锋效果都必须进行极端组合审查。

## 4. 设计阶段

### 阶段 A：关键词规则书

1. 逐个确认八类关键词的准确中文规则。
2. 确认效果目标、触发时机、结算顺序和边界条件。

4. 如需新动作，先写设计规格，不立即修改代码。

### 阶段 B：基础包逐卡设计

1. 普通稀有度卡：`c001–c027`，建议每批 5–7 张。
2. 稀有卡：`r001–r014`，建议每批 5–7 张。

1. 普通稀有度卡：`s001–s010`。
2. 稀有卡：`s011–s016`。
3. 史诗与传说：`s017–s020`。
4. 审查拓展包是否具有独立机制主题，而不是基础包的数值复制。

### 阶段 D：整体平衡审计

1. 费用曲线与各费用段卡牌数量。
2. 基础身材、关键词与效果的价值预算。
3. 普通、稀有、史诗、传说的复杂度和强度边界。
4. 快攻、中速、控制策略是否都有基本工具。

7. 简单、普通、困难 AI 是否能理解和正确使用相关卡牌。

### 阶段 E：实施前冻结

1. 72 张卡牌全部标记为“已确认”。
2. 用户审阅最终总表并明确批准进入实施。
3. 生成实施映射：设计字段 → 云数据库字段 → 战斗引擎行为。
4. 单独制定代码实施、数据迁移、云函数部署和回归测试计划。

## 19. 基础包阶段性审计

## 20. 星骸遗响核心机制方向（待选择）

星骸遗响目前只有名称、身材与背景文字，没有既定玩法。为了让拓展包具有独立身份，建议先选择一个主方向，再围绕它设计 20 张卡。三个方向都可以混入少量通用关键词，但不建议平均分配所有机制。

### 方向 A：亡语残响（推荐）

核心体验：随从死亡后仍持续产生价值，玩家主动规划交换和死亡顺序。

- 主要关键词：亡语、城墙、吸血。
- 次要关键词：少量突袭，用于主动触发有利交换。
- 代表思路：死亡时抽牌、治疗、伤害、为其他友方随从增益、召唤残骸衍生物。
- 与卡名契合：遗骨灵雀、回音萤、星骸祭司、磷焰唤灵、亡星歌姬都天然适合亡语主题。
- 优点：主题与“星骸遗响”高度一致，和基础包的综合教学定位区分明显。
- 风险：衍生物和复杂亡语可能需要扩展引擎；多卡同时死亡的结算必须非常清楚。

### 方向 B：残骸光环

核心体验：建立多个互相强化的残骸单位，保护光环核心并维持大场面。

- 主要关键词：光环、城墙、护盾。
- 次要关键词：亡语，用于光环来源死亡后的补偿。
- 代表思路：其他友方随从加攻/加血、特定条件下强化全场、城墙保护光环源。
- 与卡名契合：锈蚀卫偶、断桅巡卫、星骸巨像、遗迹执掌者适合机械残骸体系。
- 优点：构筑目标直观，能形成明显的拓展包牌组风格。
- 风险：当前光环只支持简单友方增益；叠加、离场和生命回退可能造成大量连锁死亡。

### 方向 C：裂隙进攻

核心体验：通过突袭、冲锋和固定伤害快速争夺场面并压低英雄生命。

- 主要关键词：突袭、冲锋、入场伤害。
- 次要关键词：亡语伤害。
- 代表思路：入场清理低血随从、突袭交换、冲锋补刀、死亡后继续造成伤害。
- 与卡名契合：碎陨猎手、磷光掠蝠、裂隙游猎者、寂灭星神适合进攻主题。
- 优点：对局节奏鲜明，AI 也较容易使用固定伤害和突袭单位。
- 风险：基础包已经有较多即时伤害；继续增加可能让 30 点英雄生命不足以承受稳定斩杀。

### 20.1 推荐组合

推荐以“方向 A：亡语残响”为主，少量加入方向 B 的城墙/光环保护：

- 约 8–10 张亡语或死亡联动卡。
- 约 4–5 张城墙、护盾或光环保护卡。
- 约 3–4 张突袭单位，帮助主动完成交换。
- 其余作为无效果基准、抽牌或终局卡。

这一组合最符合拓展包中文名，同时避免和基础包的冲锋/入场直伤体系过度重叠。

### 20.2 需要用户决定

- 星骸遗响选择 A、B、C 中哪一个作为主方向，或采用推荐的 A+B 混合方案。
- 是否接受为拓展包开发“召唤衍生随从”能力；这会显著丰富亡语主题，但增加引擎开发与测试范围。

### 21.5 条件提案整体审计

### 24.3 抽牌与牌库耗尽风险

候选池中基础包可通过 `c008`、`c021`、`r002`、`r006`、`r012`、`r014`、`e008` 获得额外抽牌。按同名上限全部投入时，理论额外抽牌量明显超过 20 张牌库能承受的范围。

- `c021` 与 `r014` 都是低费入场抽 1，功能高度接近，可能让任何牌组都能低成本压缩牌库。
- `r006` 入场抽 2、`s014` 亡语抽 2 在 20 张牌组里价值很高；若同时保留，需要明确疲劳伤害和手牌上限规则。
- 抽牌牌不一定强，因为它们会牺牲身材、可能爆牌并加速疲劳；正式平衡需用对局数据验证。

### 24.4 防守叠加风险

以下能力可以互相乘算，而不是简单相加：城墙改变攻击目标，护盾抵消一次伤害，生命光环提高交换门槛，治疗与吸血恢复英雄生命。

- `r004` 暮光骑士的“城墙 + 护盾”在无硬解环境中至少要求两个独立伤害事件才能越过。
- `r013` 磁核守卫同时提供城墙和生命光环，保护场面并提升其他城墙耐久，可能成为慢速牌组必带卡。
- `e007` 幽渊海主若被城墙保护并连续攻击，可能恢复大量生命；其 5/7 身材需要重点观察。
- 城墙共 13 张、护盾共 13 张，当前密度可能让依靠随从攻击的牌组频繁无法有效触及英雄。

### 24.5 光环叠加风险

- 普通稀有度同名卡牌组携带上限为三张，使 `c011` 三份攻击光环理论上可让最多 4 个其他随从各获得 +3 攻击，即单回合增加最多 12 点场面攻击。
- 两份 `r011` 的 +1/+1 光环可以互相强化，每个来源获得另一个来源的加成，其他随从获得 +2/+2。
- `l001` 同时提供永久 +1/+1 和持续 +1/+1，若己方已有 6 个其他随从，落地时可立即增加 12 点攻击与 12 点当前生命上限，收益远高于单卡身材。
- 生命光环离场可能触发批量死亡，必须保证这些死亡进入统一事件队列并正确触发亡语。

### 24.6 星骸遗响组合上限

- `s018` 亡星歌姬与 `s020` 寂灭星神的组合会主动触发全部友方亡语，并将其重复一次；若场上有多个直伤亡语，可能形成高额不可阻挡伤害。
- 若歌姬的亡语倍增允许多份叠加，两张歌姬可能形成 3 次、4 次甚至指数式触发歧义；候选规则必须固定为“不叠加，最多触发两次”。
- `s013` 一张牌生成三个随从身体，与攻击/生命光环结合时收益会快速放大；满场时只召唤可容纳数量。
- `s017` 的亡语衍生物会在清场后重新建立场面，属于合理的终局韧性，但必须明确同时死亡后释放的空位能否用于召唤。候选答案为可以。

### 61.2 星骸巨像的召唤规则

- 星骸巨像离场后才执行亡语；星骸残躯生成在己方场面的最右侧。
- 同批随从先全部离场，再依进入顺序处理亡语，因此清场前的满场不会错误阻止残躯生成。

### 61.3 亡星歌姬的倍增规则

- “额外触发一次”同时适用于自然死亡触发和寂灭星神等效果主动触发的亡语。
- 多个亡星歌姬或今后同类效果不叠加；同一个亡语在同一次触发事件中最多结算两次。
- 每次事件创建时固定触发次数；结算途中歌姬进场或离场，不改变该事件已经确定的次数。
- 同一个亡语第一次完整结算后，再从头完整结算第二次；两次之间照常执行召唤、抽牌、治疗、伤害与死亡检查。
- 亡星歌姬只影响“其他友方随从”；本卡当前没有亡语，也不能倍增自身。

### 61.4 遗迹执掌者的目标与光环规则

- “具有亡语”以当前卡牌实例是否拥有亡语效果为准，收藏卡与衍生随从均可成为目标。
- 遗迹执掌者不强化自身；多个不同来源的属性光环仍按全局规则叠加。
- 目标离开光环范围或遗迹执掌者离场时移除 +1/+1；移除生命上限后保留已受到的伤害，生命降至 0 或以下则进入死亡批次。
- 护盾只保护遗迹执掌者自身，与其光环分别结算。

### 61.5 寂灭星神的主动亡语规则

- 寂灭星神完成进场后，对当时场上所有“其他具有亡语的友方随从”建立一次快照，按场面从左到右依次触发。
- 主动触发不会使这些随从死亡、离场或失去亡语；寂灭星神不触发自身。
- 每个对象的亡语完整结算后执行死亡检查与相应死亡批次，再继续快照中的下一个对象。
- 结算期间新召唤的随从不加入本次快照；快照中的原对象之后即使离场，其已经记录的亡语仍按顺序结算。
- 亡星歌姬在本次入场效果开始时若已生效，则每个被触发的亡语结算两次；仍受“最多两次”限制。

### 64.3 直伤、抽牌与恢复

- 直接写明伤害敌方英雄的收藏卡共 6 张：`c018`、`c025`、`r001`、`s005`、`s012`、`l003`；另有 3 张衍生磷火残魂的潜在亡语伤害。
- 冲锋仅 `c005`、`c014`、`r005` 三张；按同名上限装满时，卡牌本身可提供的冲锋攻击上限为 21 点，但需要总计 19 点能量且受城墙限制，不构成单回合自然满血击杀。
- 入场直伤同名装满的理论总量为 `c025` 3 点、`r001` 4 点、`l003` 2 点，共 9 点；结合每回合 2 点英雄技能仍需实战观察快攻压血速度。
- 抽牌卡共 9 张，其中 4 张即时抽牌、5 张亡语抽牌。手牌上限为 10，溢出牌烧毁；20 张牌组进入疲劳较快，`s014` 在歌姬加成下单次可抽 4 张，是明确的资源收益同时也是疲劳风险。
- 恢复分布在入场、亡语和吸血三种通道。英雄生命上限固定 30，不允许溢出治疗转化为其他资源。

### 64.4 P1 实战观察项

以下项目没有静态证据足以要求立即改卡，但必须进入对局测试：

1. **低费直伤**：`c014`、`r001`、`r005` 与固定英雄技能共同构成快攻终结能力，观察第 5–8 回合击杀率。
2. **护盾交换效率**：`r007`、`e004`、`l002` 同时具有主动攻击能力与护盾，观察是否长期形成无损交换。
3. **铺场光环**：`c011`、`r010`、`r011`、`e001`、`l001`、`s016` 可快速放大宽场，观察单回合攻击增量和清场后恢复能力。
4. **防守拖延**：13 张城墙、生命光环、吸血及多张恢复卡可能使控制镜像过长，观察平均完整回合数和 50 回合平局率。
5. **亡语资源爆发**：`s018` 与 `s014` 可抽 4 张，和 `e003`、`s017` 可生成双份衍生物；观察手牌烧毁、场面溢出及资源优势。
6. **亡语直伤爆发**：`s018 + s020` 可重复触发 `c018`、`s005`、`s012`、磷火残魂等伤害亡语；当前受场面 7 格、9费终结者和倍增最多两次限制，但仍须专门构筑测试。

### 64.5 组合边界结论

- 没有任何卡牌生成自身、召唤寂灭星神或恢复已使用的入场效果，静态规则下不存在明确的无限循环。
- 亡星歌姬的倍增不叠加，任何单个亡语在一个事件中最多结算两次，阻断指数级倍增。
- 寂灭星神使用开始时快照，新召唤随从不加入本轮主动触发列表，阻断“召唤后继续被同一次入场递归触发”。
- 死亡批次先统一离场再处理亡语；亡语导致的新死亡进入下一批，避免重复移除和顺序不稳定。
- 允许身材相同的不同随从；按用户决定，不把纯攻血相同视为问题。审计只检查免费升级式严格压制，当前未发现必须修订的严格上下位关系。

### 64.6 现有引擎差距

当前 `cloudfunctions/battleGame/index.js` 只能直接表达基础抽牌、治疗、伤害、永久增益、友方通用属性光环及现有战斗关键词。进入实施时至少需要补齐：

1. 通用衍生随从召唤、场面上限和生成位置。
2. 同批死亡统一离场、亡语事件队列及稳定的进入顺序。
3. 敌方负面攻击光环、攻击最低为 0、来源离场恢复。
4. 按“具有亡语”筛选目标的属性光环。
5. 亡语倍增、单事件最多两次及触发次数快照。
6. 主动触发其他随从亡语、对象快照和新召唤对象排除。
7. 永久群体增益正确排除来源自身，并与临时光环分层保存。
8. 吸血对敌方英雄的战斗伤害也应治疗；治疗量按目标实际失去的生命计算，不能按过量伤害全额治疗。
9. 光环移除导致生命降至 0 时必须立即进入死亡批次。
10. AI 需要理解城墙、突袭限制、护盾、亡语价值、光环位置、入场目标和场面格数量，不能继续只按费用与攻血评分。

### 64.7 实施验收门槛

进入实施后，除第 3.4 节的 18 个关键词场景外，至少增加以下自动验证：

- 三种衍生随从在空场、6格、7格场面下的生成数量和位置。
- 双方同批死亡、双方英雄同时降至 0、亡语召唤后再次死亡的顺序。
- 两个亡星歌姬不产生三次或四次亡语；来源中途离场不改变已创建事件。
- 寂灭星神不触发自身、不递归纳入新召唤随从、对象离场后仍按快照结算。
- 遗迹执掌者只强化拥有亡语的其他友方随从，来源离场后正确回退生命上限并检查死亡。
- 时砂守御叠加、离场和攻击降至 0 的边界。
- 吸血攻击英雄、攻击护盾、过量伤害、双方随从互相造成伤害的实际治疗量。
- 手牌 9/10 张时抽 2/4 张、牌库不足时连续疲劳、疲劳导致双方同时死亡。
- 简单、普通、困难 AI 均能合法使用 72 张卡，不发生非法目标、满场召唤或突袭攻击英雄。
- 使用固定随机种子执行不少于 1,000 局 AI 对局，记录先后手胜率、平均回合、卡牌使用率、手牌烧毁率、疲劳率和 50 回合平局率；没有数据前不宣称最终数值平衡。
