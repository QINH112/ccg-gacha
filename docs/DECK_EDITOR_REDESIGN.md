# 牌组编辑器改版（2026-11-19）

用户原话：「我要升级我的牌组界面，如图现在的界面，让玩家根本不知道怎么组卡」。

问题：旧界面左边是「费用 ◇ 卡名 / 攻血 / 普+ 闪+」的文字行，右边也是文字行，
玩家看不出「点一下就能加」，也看不到自己牌组的费用分布，组卡全靠猜。

## 2. 布局（以 375×812 为基准，按宽度等比）

```
标题：牌组名
副标题：已选 20 / 20 · 同名上限普通/闪卡共享
[改名] [洞察] [复制] [清空]          ← 四等分，高 28
[保存牌组（未完成）]   [一键补满]     ← 保存占 58%，补满占其余
[搜索卡牌] [全部卡牌] [排序：费用]    ← 三等分，高 27
┌ 法力曲线 ─────────────┐
│ 1..10 费的柱状图 + 柱顶张数 │        ← 高 58
└───────────────────────┘
收藏卡牌（点一下加入）      当前牌组 20/20
┌卡面┐┌卡面┐             ┌名字 / N 费 · 稀有度 ┐
│1/3 ││0/3 │             │[普通 2] [闪卡 1]     │
└────┘└────┘             └─────────────────────┘
```

- 左栏宽 `floor(W * 0.6)`，两列卡面宽 `floor((leftW - m - 10) / 2)`，卡面高 `宽 × 1.42`。
- 卡面顶部压一条深色信息带：左「N 费」、右「已用/同名上限」。
- 右下角绿色小圆点表示「这张还有没放进去的库存」。
- 右栏每行 50 高：卡名、`N 费 · 稀有度`、底部两个按钮块（普通 N / 闪卡 N），点按钮减一张。
- 两栏**各自独立滚动**：`state.deckScroll.left` / `.right` 分别记录，手指落在左半屏只滚卡阵、落在右半屏只滚当前牌组（`clientX < W * 0.6` 判定），两栏各自画细滚动条。

### 3.1 加卡与减卡

- 卡面右下角有「闪」小按钮时，点它加的是闪卡版；没有闪卡库存时显示绿色圆点表示「还有普通版可以加」。
- 当前牌组标题下常驻一行小字「点下面的数字减一张」，右侧每行左边是小卡图（只画立绘，不画整张卡框）、右边是卡名与「普通 N / 闪卡 N」按钮。
- 空状态：牌组一张卡都没有时，右栏显示「还没有卡牌 / 点左侧卡面 / 就能加入牌组」；筛选后无结果时左栏显示「没有符合条件的卡牌 / 试试点「全部卡牌」清掉筛选」。


## 3. 交互细节

- 点卡面加卡：先加普通版；普通版用尽且还有闪卡时自动加闪卡；同名总数达上限或牌组满 20 时用顶部一行提示（`notifyError`），不弹窗。
- 一键补满：按当前筛选与排序遍历，逐张补普通版，直到 20 张或无可补，结束 toast「补入 N 张」。
- 排序切换：`费用 → 稀有度 → 卡包 → 拥有数量` 循环。
- 筛选面板：与图鉴同款（卡包 / 稀有度 / 费用多选 + 清除全部），标题写作「筛选卡牌」，关闭用面板右上角或点面板外。
- 搜索：点「搜索卡牌」调用 `wx.showModal({ editable: true })`，与图鉴同一个搜索口径（名称/ID/规则/关键词）。
- 保存仍是手动（点「保存牌组」），未满 20 张时按钮文案变「保存牌组（未完成）」，与 `deckService.save` 的「允许保存未完成牌组、但不可开战」一致。

## 4. 自动化

| 脚本 | 断言 |
| --- | --- |
| `tools/test_deck_editor_ui.js` | 320×568 / 375×812 / 430×932 三种宽度各跑一遍：2 列网格且不越界、点卡面加一张、同名上限拦截并提示、点数字减一张、一键补满到 20、满 20 再点被拒、法力曲线合计等于牌组张数、筛选与搜索生效、空状态文案、点「清空」归零 |
| `tools/test_deck_editor_consistency.js` | 满 20 张可通过 `deckService.validate`；19 张报「需要 20 张」；同名超限报「最多可放 N 张」；超拥有数量报「超出拥有数量」；一键补满的结果必须通过服务端校验 |
| `tools/test_deck_rules.js` | 服务端侧的同名上限、版本不可互补、不可用卡等规则（既有） |
| `tools/render_deck_editor.js` | 用真实 canvas 渲染样张，产物 `design/review/deck-editor-<宽>x<高>.png` |

跑法：

```bash
node tools/test_deck_editor_ui.js
node tools/test_deck_editor_consistency.js
node --expose-gc tools/test_deck_rules.js
node tools/render_deck_editor.js 375x812
```

## 6. 我的牌组列表页（同一轮改版）

每副牌组一行，高 118：

- 左侧 56×82 封面（该牌组里稀有度最高、费用最高的那张的立绘）+ 卡名。
- 中间三行：牌组名（13px 加粗）、`20 / 20 · 可用`（可用绿色、未完成金色）、技能名。
- 下方 1–10 费迷你费用分布柱状图，右下角标「费用分布」。
- 右侧按钮：有牌时「编辑」，空槽位「新建」。

样张：`node tools/render_deck_editor.js 375x812 list` → `design/review/deck-list-375x812.png`。

## 卡面尺寸与文字（2026-11-20）

- 所有卡面按卡框贴图 512×768 的比例绘制（`const CARD_RATIO = 768/512`），牌组网格 `ch = cw * CARD_RATIO`。
- 卡面说明文字：字号 `max(7, w * 0.062)`、行高 `max(8, h * 0.045)`、最多 2 行；起始 `y + h*0.645`，保证不压底部攻/血徽章。
- 样张渲染器在 `render()` 前 `wait(600)`，等卡框与立绘真正 load，否则出的是程序化兜底样式，和真机不一致。
