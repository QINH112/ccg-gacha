# 星界召唤 CCG 微信小游戏 / 小程序原生抽卡 Demo

原生微信小程序 + TypeScript + WXML + WXSS。实现：
- 单抽、五连、十连
- Common/Rare/Epic/Legendary 概率配置
- 十连至少一张史诗或传说保底
- 抽卡翻转动画、结果展示
- 卡牌库存、重复统计、本地存档
- 三张同名普通卡合成闪耀卡（不改变战斗属性）
- 卡牌图鉴与合成页面

## 导入运行
1. 解压 ZIP。
2. 使用微信开发者工具「导入项目」，项目目录选择本目录。
3. AppID 可选择测试号或填入自己的 AppID。
4. 工具中确认基础库版本支持 TypeScript 编译；如需使用项目内 TS，建议微信开发者工具中开启 TypeScript 编译支持。
5. 点击编译/预览。

## 重要说明
- 本项目是可运行的前端原型，抽卡随机数在客户端，本地存档使用 `wx.setStorageSync`。
- 商业/线上游戏应将抽卡随机、概率、保底、库存变更迁移至服务端，客户端只展示结果；同时检查微信平台及所在地相关合规要求。
- 十连保底规则：十连结果中若自然抽取没有史诗/传说，则将第 10 张替换为史诗/传说；替换档位按史诗 80%、传说 20%。
- 合成规则：同名卡普通版本库存 >=3 时可合成 1 张闪耀版本；闪耀卡不参与再次合成。
